## 💻 Tech Stack & Features
- **Frontend**: Pure Semantic HTML5, Vanilla Modern CSS3, Vanilla ES6 JavaScript (Zero build step, instant load)
- **Typography**: Google Fonts (`Outfit` & `Plus Jakarta Sans`)
- **Icons**: Lucide Icons CDN
- **Key Interactive Features**:
  1. **Preloader Animation**: Brand cross & heartbeat ECG pulse animation
  2. **Interactive 4-Step Appointment Wizard**: Department → Doctor & Mode → Date & Slot → Patient Info with Token Slip & WhatsApp Sync
  3. **Diagnostic Test Catalog & Real-Time Price Calculator**: Search & filter 15+ tests, add/remove with animated badge and cart total
  4. **Home Blood Sample Collection Booking**: Modal with date/time slot & doorstep address collection in Madhapur
  5. **Smart Symptom Matcher**: One-click chip selector guiding patients to the right specialist doctor & test
  6. **WhatsApp Digital Report Request**: Fast lookup modal delivering lab results straight to patient's WhatsApp
  7. **Mobile Sticky Action Bar**: Instant call, WhatsApp, and booking access for smartphone users
  8. **Full Schema.org JSON-LD**: Comprehensive local business SEO structure for search engines

## 🚀 How to Run Locally

You can preview the website by simply opening `index.html` in any web browser, or serving it with any local web server:

```powershell
# Using Python:
python -m http.server 8080 --directory c:\Users\Acer\Downloads\Pulse\svv

# Or using Node / npx:
npx serve c:\Users\Acer\Downloads\Pulse\svv
```
Then visit `http://localhost:8080/` in your browser.
